# Student Management System

## Description

A console-based Student Management System built with Python and SQLite. The project allows users to add, view, search, update, and delete student records.

## Features

- Add student
- View all students
- Search student by name or roll number
- Update student information
- Delete student
- Input validation
- Automatic result calculation based on marks
- SQLite database for data storage
- Formatted console output

## Technologies Used

- Python
- SQLite
- Object-Oriented Programming (OOP)

## Project Structure

- `main.py` - Main program and menu
- `operations.py` - Database and student operations
- `student.py` - Student class and result calculation
- `validators.py` - Input validation
- `project.py` - Project information
- `Students_Data.db` - SQLite database

## Main Operations

### Add Student
Adds a new student with name, age, and marks.

### View Students
Displays all stored students in a formatted table.

### Search Student
Searches for a student by name or roll number.

### Update Student
Updates the name, age, and marks of an existing student.

### Delete Student
Deletes a student record using the roll number.

### Result Calculation
The result is automatically calculated from the student's marks.
The result is not stored separately in the database.
